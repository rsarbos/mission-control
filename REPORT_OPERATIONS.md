# RSARBOS Manual Report Operations

## Analyst Checklist

Use this sequence for every paid manual underwriting request.

1. Confirm payment status is `paid`.
2. Open submitted property URL and verify address.
3. Capture property facts: beds, baths, square footage, year built, HOA, list price, MLS/source.
4. Pull nearby sales comps and note direct relevance.
5. Pull rental comps and separate true subject-like comps from larger/different asset types.
6. Build the ARV thesis: current value, light refresh upside, moderate upside, and caution case.
7. Identify risk notes: HOA, special assessments, rental restrictions, condition, financing, exit buyer pool.
8. Complete strategy fit scoring.
9. Add neighborhood intelligence: walkability, schools, safety, market velocity.
10. Add source appendix and explicit diligence items.
11. QA the report for clarity, math, typos, and unsupported claims.
12. Deliver private report link by email.

## Delivery Process

1. Generate the report from the latest approved dossier template.
2. Export or publish the report to a private link.
3. Send the customer a short delivery email with the private link.
4. Mark internal request status as `fulfilled` after delivery.

## Turnaround Rules

- Standard: deliver within 24 hours after confirmed payment.
- High urgency: prioritize same-day review when capacity allows.
- If submitted data is incomplete, send the incomplete-submission response within 4 business hours.
- If third-party sources conflict, include the conflict in the report instead of hiding it.
