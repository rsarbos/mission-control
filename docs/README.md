# RSARBOS Mission Control Docs

Supporting documentation is grouped by operating area:

- `mission-control/` - private UI implementation notes, handoff records, and structure docs.
- `operations/` - manual report fulfillment, payment, delivery, and Stripe flow docs.
- `revenue/` - launch outreach, marketing starter material, and social asset planning.
- `website/` - public website readiness, data source review, and pre-marketing tasks.

Keep root files limited to repository entrypoints, package/deployment config, and `AGENTS_REQUIRED_READING.md`.
