# CONSTITUTION — AXIOM-CORE

Inherits from: /axiom/AXIOM_CONSTITUTION.md

## Purpose
Provide engineering rules and standards that implement the AXIOM doctrine.

## Engineering Addendum
- Infrastructure as Code is the default.
- Observability and telemetry first (logs, metrics, traces).
- Automated testing and CI/CD for all changes.
- Secure-by-default: least privilege and secret management.
- Immutable infrastructure and reproducible builds.
- Change approvals, auditing, and replayable deployments.
